ค่าอินพุตที่ใช้คำนวณ

  • VCC = {{ "%.2f"|format(result.vcc) }} V, VBE = {{ "%.2f"|format(result.vbe) }} V, β = {{ "%.0f"|format(result.beta) }}
  • R1 = {{ "%.0f"|format(result.r1) }} Ω ({{ "%.1f"|format(result.r1 / 1000) }} kΩ), R2 = {{ "%.0f"|format(result.r2) }} Ω ({{ "%.1f"|format(result.r2 / 1000) }} kΩ)
  • RC = {{ "%.0f"|format(result.rc) }} Ω ({{ "%.1f"|format(result.rc / 1000) }} kΩ), RE = {{ "%.0f"|format(result.re) }} Ω ({{ "%.1f"|format(result.re / 1000) }} kΩ)

ขั้นตอนการคำนวณ (Forward-Active Approximation)

  1. VTH = VCC × R2/(R1+R2) = {{ "%.4f"|format(result.vth) }} V
  2. RTH = R1·R2/(R1+R2) = {{ "%.1f"|format(result.rth) }} Ω
  3. IB = (VTH−VBE)/(RTH+(β+1)·RE) = {{ "%.4e"|format(result.ib) }} A
  4. IC = β·IB = {{ "%.4e"|format(result.ic) }} A, IE = (β+1)·IB = {{ "%.4e"|format(result.ie) }} A
  5. VE = IE·RE, VB = VE+VBE, VC = VCC−IC·RC, VCE = VC−VE

สมมติฐานและข้อจำกัด

  • ทรานซิสเตอร์ NPN ในสภาวะ Forward-Active: ถือว่า β คงที่และ VBE คงที่ตามค่าที่กรอก
  • เกณฑ์ตรวจภูมิภาค: Cutoff เมื่อ VTH ≤ VBE · Saturation เมื่อ VCE < 0.2 V (ค่า VCE(sat) โดยประมาณ)
  • ไม่ใช่ SPICE: ไม่มี Early effect, ความเสียภาษีของสภาวะอิ่มตัวจริง หรือพารามิเตอร์ไบอัสที่ไม่เชิงเส้น — ผลที่อยู่นอก Active Region จึงแสดงพร้อมคำเตือนเสมอ
